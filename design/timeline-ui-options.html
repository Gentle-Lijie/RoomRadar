时间对比 · UI 方案

四套「时间对比」视图改版，全部沿用应用现有 token（card / border / secondary 表头 / 占用 #e8aa70 / 空闲 preview-free），仅布局不同。共同点：教室+容量列固定宽度（名称超长省略号，容量右对齐等宽数字），左上角 UNNC 校徽，表格可横向滚动时房间列吸左。示例数据为演示用。

方案 A

合并时段块

在现行网格节奏上把连续预约画成一整块圆角色块，一眼读出时段长短；房间列固定 205px。

方案 B

标签日程条

更高的行程条直接内嵌「时间 · 事项」文字，无需悬停即可读；行高 30px，房间列固定 215px。

方案 C

楼栋分组网格

保留现行离散格子，但按楼栋分组、行尾新增固定 96px「下一个空闲」提示列；房间列固定 205px。

方案 D

高密度紧凑条

行高 15px 的连续色带，同屏可容纳三倍房间数，适合 200+ 间总览；房间列固定 172px。
